# firebase_testlab_detector_example

Displays whether the Android Test Lab system setting is enabled. Ordinary local emulators report that they are outside Test Lab. Other platforms and registration errors display the same false state.

Flutter 3.47 or newer. Detection runs on Android API 24 or newer.

For Android tooling and platform requirements, see the [package README](../README.md).

From this directory, select a compatible Flutter SDK with FVM, then run:

```sh
fvm flutter pub get
fvm flutter run -d <device-id>
```
